# Koltugun Altindaki Kumanda Avcisi

## Resmi Bildiri

Bu yazilim, 21. yuzyilin en kritik milli meselelerinden birini cozmek uzere gelistirilmistir: **koltugun yastiginin altina kacan uzaktan kumanda**.

Bilim, teknoloji ve biraz da umutsuzluk bir araya gelerek bu protokolu ortaya cikarmistir. Protokol ISO sertifikali degildir. ISO'nun haberi yoktur. ISO'nun haberi olmasin.

## Neden Bu Kadar Ciddi?

Cunku kumanda kaybolunca:
- dizi yarida kalir
- evdeki en yetkili kisi "ben koymadim" der
- herkes ayni yastigi uc kez kaldirir
- sonra ayni yastigi dorduncu kez kaldirir

Bu dongu, evrenin entropisini artirir.

## Kurulum

```bash
python3 avci.py
```

Ileri seviye (tavsiye edilmez):

```bash
python3 avci.py --inanc
python3 avci.py --gizli
```

## Bilimsel Yontem

1. Yastigi kaldir.
2. Hicbir sey bulama.
3. Yastigi geri koy.
4. Ayni yastigi tekrar kaldir.
5. Varolussal bir cumle soyle.
6. Kumandayi genelde elinde oldugunu fark et.

## Sorumluluk Reddi

Bu yazilim gercek kumanda bulmaz. Gercek kumanda zaten senin elinde. Yazilim sadece bunu gec fark etmeni saglar.
